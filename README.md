## 📝 Description
Welcome to the **BSCWD234406-Java** project repository. This application is developed as part of the `BSC-WD-23-44-06` module, focusing on Java enterprise/desktop application development integrated with a robust database backend. 

It features a complete business management system tailored for **ABC Company**, handling data persistence, business logic, and a user-friendly interface.

---

## ✨ Features
* **Database Integration:** Seamless connection to the `abc_company` database schema.
* **Data Management:** Full CRUD (Create, Read, Update, Delete) operations.
* **Structured Architecture:** Clean separated packages for source files (`src/`) and configuration files.

---

## 📁 Repository Structure
Here is an overview of the key files in this project:

| File / Folder | Description |
| :--- | :--- |
| 📂 `src/` | Contains the core Java source code and packages. |
| 🗄️ `abc_company.sql` | The database backup/script to set up tables and sample data. |
| 🛠️ `build.xml` | Ant build script configuration for compiling the project. |
| ⚙️ `nbproject/` | Project metadata and configurations for NetBeans IDE. |
